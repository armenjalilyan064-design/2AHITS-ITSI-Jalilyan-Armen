 # Arbeitsbericht am 07.01.2026 

- Name: Armen Jalilyan
- Klasse: 2 AHITS
- Datum: 07.01.2026
- Fach: ITS1
- Thema: Gesamter Ablauf Arbeitsbericht über GitHub Pages verfügbar zu machen.

- 1: Gehe auf github.com und melde dich an.
- 2: Klicke auf New Repository.
- 3: Gib einen Namen für das Projekt ein.
- 4: Klicke auf Create Repository.
- 5: Offne dein Bericht in Replit.
- 6: Klicke im Projekt auf Tools -> Git.
- 7: Wähle Version Control / GitHub aus.
- 8: Klicke auf Connect to GitHub.
- 9: Dann Erlaube Replit den Zugriff auf GitHub.
- 10: Wähle das zuvor erstellte Repository aus.
- 11: Bestätige dann die Verbindung.
- 12: Klicke auf das GitHub Version-Control-Symbol.
- 13: Schreibe eine Commit-Nachricht.
- 14: Klicke auf Commit & Push.
- 15: Gehe auf github.com und öffne dein Repository.
- 16: Klicke auf Settings -> Pages.
- 17: Wähle unter Source den Branch main aus.
- 18: Klicke auf Save.
- 19: Kopiere die angezeigte GitHub Pages-URL.
- 20: Öffne die URL in ein Browser und prüfe ob dein Bericht richtig angezeigt wird.
- 21: Ändere den link dann ganz am Ende mit .Html
- 22: Gib den HTML-Link auf Teams ab.
