# 2: Der Befehl

- Mit dem Befehl echo kann man Text im Terminal ausgeben oder direkt in eine Datei schreiben.
Zum Beispiel:
echo Hallo Welt >hallo.txt
→ Dieser Befehl erstellt (oder überschreibt) eine Datei mit dem Namen hallo.txt und schreibt den Text „Hallo Welt“ hinein.

- Wenn man > verwendet, wird der vorhandene Inhalt der Datei überschrieben.
- Wenn man dagegen >> verwendet, wird der neue Text am Ende der Datei angehängt.

``` sh
echo Hallo 2AHITS >hallo.txt
echo Hallo Welt >>hallo.txt
echo Weitere Zeile >>hallo.txt
```
- Nach diesen Befehlen enthält die Datei:
``` sh
Hallo 2AHITS
Hallo Welt
Weitere Zeile
```
- Mit cat hallo.txt kann man den gesamten Inhalt der Datei anzeigen.
Mit cat hallo.txt test.txt kann man mehrere Dateien hintereinander anzeigen lassen.

# 3. Eingabe- und Ausgaberichtungen (< und >)

- Der Befehl cat <test.txt bedeutet, dass die Eingabe nicht von der Tastatur kommt, sondern aus der Datei test.txt gelesen wird.
Das <-Zeichen leitet also die Eingabe um.
In diesem Fall zeigt cat den Inhalt der Datei auf dem Bildschirm an, genauso wie bei cat test.txt.

```sh
cat <hallo.txt
```

# 5. Ordner mit Leerzeichen im Namen

- Wenn ein Ordner oder eine Datei Leerzeichen im Namen enthält, muss der Name in Anführungszeichen gesetzt werden.
Andernfalls denkt die Shell, es wären zwei verschiedene Argumente.

``` sh
mkdir 'Urlaubs Fotos'
```
- Ohne Anführungszeichen hätte das System versucht, zwei Ordner zu erstellen: Urlaubs und Fotos.
- Mit den einfachen Anführungszeichen ' ' erkennt die Shell, dass es sich um einen einzigen Ordnernamen handelt.

# 6. Anführungszeichen und Sonderzeichen (Quotes)

- Mit einfachen Anführungszeichen ' ' kann man verhindern, dass die Shell Sonderzeichen oder Befehle interpretiert.
- Das bedeutet: Der Text wird genau so ausgegeben, wie er eingegeben wurde.

``` sh
echo >>> ACHTUNG <<<
```
- Dieser Befehl funktioniert nicht, weil das Zeichen > eine Umleitung bedeutet.
Die Shell versucht, die Ausgabe umzuleiten und gibt eine Fehlermeldung aus.

Korrekt ist:
``` sh 
echo '>>> ACHTUNG <<<'
```
- Durch die einfachen Anführungszeichen ' ' erkennt die Shell, dass es sich um normalen Text handelt – und der Text wird fehlerfrei ausgegeben:
``` sh
>>> ACHTUNG <<<
```
# 7. Der Befehl ls

- Mit ls werden die Inhalte des aktuellen Verzeichnisses angezeigt.
- Wenn man ls -l verwendet, erhält man eine detaillierte Liste mit Dateigrößen, Berechtigungen, Eigentümern und Änderungsdaten.
- Das hilft, um schnell zu sehen, welche Dateien oder Ordner vorhanden sind und wem sie gehören.

# Übung 9 - (Here-Documents)

- Aufgabe: Informiere dich über die Here-Documents Schreibweise (=Syntax) und führe damit die Aufgabenstellungen „Textdatei erstellen“ und „C Hallo Welt“ noch einmal aus.

- Ein Here-Document ist eine Möglichkeit, einem Programm eine mehrzeilige Eingabe direkt aus dem Terminal zu übergeben.
Alles, was zwischen zwei festgelegten Begrenzern (z. B. EOF) steht, wird vollständig und unverandert als Eingabe an das Programm weitergeleitet.

``` sh 
command <<EOF
Zeile 1
Zeile 2
...
EOF
```
- Lösung:
``` sh
cat <<EOF > made_by_echoing.txt
=========================
        HTL BRAUNAU
=========================
= 2AHITS Gruppe n       =
= x Schülerinnen        =
= y Schüler             =
=========================
EOF
```
