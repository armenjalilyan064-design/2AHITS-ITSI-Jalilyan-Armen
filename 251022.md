## Übung 3

# rm
- Löscht Dateien oder Verzeichnisse.  
- Option `-r`: löscht Verzeichnisse rekursiv inklusive Inhalt.  
- Option `-f`: erzwingt das Löschen ohne Nachfrage.  
- Vorsicht: Gelöschte Dateien können nicht wiederhergestellt werden.

# rmdir
- Löscht nur **leere Verzeichnisse**.  
- Funktioniert nicht, wenn im Verzeichnis noch Dateien enthalten sind.

# cp 
- Kopiert Dateien oder Verzeichnisse.  
- Option `-r`: Kopiert Verzeichnisse inklusive aller Unterverzeichnisse und Dateien.  
- Option `-v`: zeigt, welche Dateien kopiert werden.

# mv
- Verschiebt Dateien oder Verzeichnisse an einen anderen Ort.  
- Kann auch zum **Umbenennen** von Dateien/Verzeichnissen verwendet werden.  
- Option `-i`: fragt vor Überschreiben von Dateien nach.  
- Option `-v`: zeigt die ausgeführten Aktionen an.

## Lösung
```bash

### Erkenntnisse:

# ls
- Mit `ls` kann man sich Dateien und Ordner im aktuellen Verzeichnis anzeigen lassen.  
- `-l` zeigt alles in einer **detaillierten Liste** an (Berechtigungen, Größe, Besitzer, Datum).  
- `-a` zeigt auch **versteckte Dateien** (Dateien, die mit `.` beginnen).  
- `-h` macht die Dateigrößen **menschenfreundlich** (KB, MB, GB).  
- `-R` listet **alle Unterverzeichnisse rekursiv** auf.  
- Mit `--color=auto` werden die Dateien **farblich nach Typ** hervorgehoben, was die Übersicht erleichtert.

# mv
- `mv` kann Dateien oder Ordner **verschieben** oder **umbenennen**.  
- Mit `-i` fragt das System **vor dem Überschreiben**, sodass man nichts aus Versehen löscht.  
- Mit `-v` sieht man genau, welche Dateien verschoben oder umbenannt wurden.  
- `-n` verhindert, dass bestehende Dateien überschrieben werden.

 # rm
- `rm` löscht Dateien.  
- Mit `-r` kann man **ein ganzes Verzeichnis mit allem Inhalt** löschen.  
- `-f` erzwingt das Löschen, das System fragt also nicht nach.  
- `-i` fragt bei jeder Datei nach, bevor sie gelöscht wird, sehr praktisch, um Fehler zu vermeiden.
