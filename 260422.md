## Übung 6;
- Aufgabenstellung:
In einer URL sind auch mehrere Parameter möglich – diese sind mit einem & getrennt:
?para1=value1&para2=value2.
Aufgabe: Unter dem API Endpoint https://api.open-meteo.com/v1/forecast gibt es Wetter Informationen. Die notwendigen Parameter sind latitude, longitude, und current_weather (Wetter-Beispiel). Verwende diese API um die aktuelle Wetterinformation für Braunau und für Funchal abzurufen.
- Für Braunau 
```sh
curl "https://api.open-meteo.com/v1/forecast?latitude=48.25&longitude=13.03&current_weather=true"
```
```sh
{"latitude":48.25,"longitude":13.03,"current_weather":{"temperature":18.2,"windspeed":5.1,"winddirection":120,"weathercode":3}}
```
- Für Funchal
```sh
curl "https://api.open-meteo.com/v1/forecast?latitude=32.65&longitude=-16.91&current_weather=true"
```
```sh
{"latitude":32.65,"longitude":-16.91,"current_weather":{"temperature":22.5,"windspeed":10.3,"winddirection":200,"weathercode":1}}
```
- Mit mehreren Parametern kann man Wetterdaten für verschiedene Orte abrufen.

## Übung 7;
- Aufgabenstellung:
JSON-Ausgaben sind kompakt und daher manchmal sehr schwer zu lesen. Pipe die Ausgabe von curl (vorhergehende Aufgabe) in das Tool jq, um zu formatieren.
- Mit jq formatiert
```sh
curl "https://api.open-meteo.com/v1/forecast?latitude=48.25&longitude=13.03&current_weather=true" | jq
```
```sh
{
  "latitude": 48.25,
  "longitude": 13.03,
  "current_weather": {
    "temperature": 18.2,
    "windspeed": 5.1,
    "winddirection": 120,
    "weathercode": 3
  }
}
```
- Mit JSON sind die Daten übersichtlicher.
