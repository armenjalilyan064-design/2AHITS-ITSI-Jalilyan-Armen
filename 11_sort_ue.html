sort – Übungen

Grundlegende bash Tools

Mit per Pipe | verknüpften Befehlen ergeben sich viele Möglichkeiten. Zum Beispiel das Tool sort mit dem Daten sortiert werden können.

Beispiel

Sortiere die Einkaufsliste shopping.txt (download der Datei mit curl), gib dann nur die letzten 5 Zeilen aus.

Die letzten 5 Zeilen der unsortierten Datei:

$ cat shopping.txt | tail -n5

Den Inhalt der Datei in sortierter Reihenfolge:

$ cat shopping.txt | sort

Die letzten 5 Zeilen der sortierten Datei:

$ cat shopping.txt | sort | tail -n5

Übung (Zwei Files kombinieren)

Download shopping2.txt. Sortiere den Inhalt von shopping.txt kombiniert mit shopping2.txt und gib von diesem sortierten Ergebnis die letzten 15 Zeilen aus.

Hinweis: cat kann mehr als eine Datei zusammenfügen:

cat shopping.txt shopping2.txt

Ergibt auf stdout die beiden Dateien hintereinander.

Übung (Sort)

Mit der Datei shopping.txt – löse jeden Punkt durch einen Einzeiler mit Hilfe von Pipes:

  • Sortiere in umgekehrter Reihenfolge (eine Option von sort)
  • Sortiere nach der 2ten Spalte – Obstnamen (dies ist ebenfalls eine Option von sort)
  • Nimm alles bis auf die ersten 5 und letzten 5 Zeilen, sortiere das nach Personennamen in absteigender Reihenfolge ('Z' zuerst). Sortiere das Ergebnis aufsteigend nach Obstnamen und gibt die letzten 3 Zeilen des Endergebnisses aus.

Übung (Namensliste)

Erstelle mit cut, sort und uniq eine alphabetisch sortierte Liste an Namen die in shopping.txt vorkommen. Jeder Name soll in dieser Liste nur einmal stehen.

Übung (Middle)

Gib von shopping.txt alles bis auf die ersten zwei und die letzten zwei Zeilen aus. Hinweis: die -n Option von head und tail erlaubt dies durch eine spezielle Angabe bei der Zeilenanzahl. Löse durch einen Einzeiler mit Hilfe von Pipes.

Übung (Numeric Sort)

Recherchiere die sort Option -n, --numeric-sort und erkläre (auch anhand eines Beispiels) die Auswirkung wenn diese Option angegeben oder nicht angegeben ist.

Hinweis: Sortiere eine Datei die ein- und zweistellige Zahlen gemischt untereinander enthält.

Übung (Sort Optionen)

Erkläre – mit Beispielen – die sort Optionen:

  • -m, --merge
  • -R, --random-sort

Übung (Letzte 5 von beiden)

Nimm jeweils von shopping.txt und von shopping2.txt die letzten 5 Zeilen, füge diese zusammen und sortiere das Ergebnis (10 Zeilen).

Hinweis: cat kann auch ein File und Standard-Input zusammenfügen. - steht dabei für Standard Input:

$ cat shopping.txt | cat shopping2.txt -

Erklärung: Der Output des ersten cat wird an das 2te cat weitergegeben. Das 2te cat fügt an den Inhalt von shopping2.txt die über stdin empfangenen Daten an.

Anleitung:

  • Nimm von shopping.txt die letzten 5 Zeilen (mit tail) und füge diese an den Inhalt von shopping2.txt an (mit cat wie oben erklärt).
  • Nimm vom Ergebnis die letzten 10 Zeilen (mit tail)
  • Sortiere das Ergebnis
