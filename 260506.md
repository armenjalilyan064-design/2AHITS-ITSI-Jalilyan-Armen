## Übung (curl und Notenmanagement):

```sh
curl 'https://notenmanagement.htl-braunau.at/rest/api/...'
```
- Damit kann man die gleichen Daten wie im Browser im Terminal anzeigen.

```sh
curl -H "Cookie: SESSION=..." https://notenmanagement.htl-braunau.at/rest/api/...
```
- Ohne Session geht es nicht, weil man sonst nicht eingeloggt ist.

## Übung (curl und Notenmanagement II):

```sh
POST /rest/Token
username + password senden
```
- Damit bekommt man ein Token zurück.

```sh
{
  "access_token": "xxx",
  "role": "Schueler"
}
```
- Das Token braucht man dann für alle weiteren Requests.

```sh
curl -H "Authorization: bearer TOKEN" \
https://notenmanagement.htl-braunau.at/rest/api/Schueler/5013/Noten
```
- Damit bekommt man die Noten vom Schüler.

```sh
curl "https://notenmanagement.htl-braunau.at/rest/api/LFs/LF_ID"
```
- Lädt eine Leistungsfeststellung.

```sh
?limit=10&sort=Datum|-Datum
```
- Damit kann man Ergebnisse begrenzen und sortieren.
