## Komplettes Löschen vom Wurzelverzeichnis
Dieser Befehl löscht, vom Wurzelverzeichnis ausgehend, alles.
```sh
rm -r /
```
## Auflisten des Inhalts des Wurzelverzeichnisses
Dieser Befehl zeigt den Inhalt des Wurzelverzeichnis.

```sh
ls /
```

```sh
bin   dev  home    io   lib64  mnt  opt   proc  root  sbin  store  tmp  var
boot  etc  inject  lib  media  nix  pid2  repl  run   srv   sys    usr
```
## Aktuelles Verzeichnis anzeigen (Pfad zum Arbeitsverzeichnis)
Dieser Befehl  gibt den vollständigen Pfad des aktuellen Verzeichnisses in der Befehlszeile aus.
```sh
pwd 
```
## Verzeichniswechsel in der Kommandozeile
 Dieser Befehl wird in der Kommandozeile verwendet, um vom aktuellen Verzeichnis zu einem anderen zu wechseln
 ```sh
 cd
 ```
 ## Neues Verzeichnis erstellen (Ordner anlegen)
Dieser Befehl erstellt im Terminal oder in der Eingabeaufforderung einen neuen Ordner (Verzeichnis) mit dem Namen test. mkdir ist die Kurzform für "make directory" und das hierfür angegebene test ist der Name des neuen Ordners. 
```sh
mkdir
```
## Verzeichnisinhalt anzeigen (Dateien und Unterordner auflisten)
Dieser Befehl wird verwendet, um den Inhalt eines Verzeichnisses (Dateien und Unterverzeichnisse) aufzulisten.
```sh
ls
```
```sh
250924.md  berichte       image_2.png  image_4.png  README.md
251008.md  grundlagen.md  image_3.png  image.png    test
```
## Wechsel in ein Unterverzeichnis
Der Befehl cd test/ wechselt das aktuelle Arbeitsverzeichnis in ein Unterverzeichnis namens test, das sich direkt im aktuellen Verzeichnis befindet. 
```sh
cd test/
```
## Neue leere Datei erstellen
Der Befehl touch neu.txt erstellt eine neue, leere Datei namens neu.txt, wenn sie noch nicht existiert.
```sh
touch neu.txt
```
## Detaillierte Auflistung von Dateien und Verzeichnissen
Der Befehl ls -l listet den Inhalt eines Verzeichnisses auf, wobei jede Datei und jedes Verzeichnis in einer eigenen Zeile mit zusätzlichen Informationen wie Dateityp, Berechtigungen, Eigentümer, Gruppe, Größe und letzter Änderungsdatum aufgeführt wird.
```sh
ls -l
```
## Wechsel ins Stammverzeichnis der aktuellen Partition
Der Befehl cd/ wechselt in das Stammverzeichnis der aktuellen Partition oder des aktuellen Laufwerks.
```sh
cd/
```
## Neue leere Datei anlegen
Der Befehl touch x.txt erstellt eine neue, leere Textdatei namens x.txt, sofern diese noch nicht existiert.
```sh
touch x.txt
```
## Wechsel ins Home-Verzeichnis des aktuellen Benutzers
Der Befehl cd ~ in der Kommandozeile navigiert zum Home-Verzeichnis des aktuellen Benutzers.
```sh
cd ~
```
## Datei löschen (unwiderruflich)
Der Befehl rm neu.txt ist ein Kommando in der Linux/Unix-Shell, das die Datei namens neu.txt aus dem aktuellen Verzeichnis unwiderruflich löscht. 
```sh
rm neu.txt
```
## Verzeichnis eine Ebene nach oben wechseln
Der Befehl cd .. ist eine Anweisung in der Kommandozeile (Terminal), um vom aktuellen Verzeichnis eine Ebene nach oben in das Elternverzeichnis zu wechseln.
```sh
cd ..
```
## Datei in einem Unterordner löschen
Der Befehl rm test/neu.txt löscht die Datei neu.txt aus dem Unterordner test im aktuellen Verzeichnis und entfernt sie unwiederbringlich. 
```sh
rm test/neu.txt
```
## Inhalt des übergeordneten Verzeichnisses zwei Ebenen höher anzeigen
Der Befehl ls ../.. listet den Inhalt des übergeordneten Verzeichnisses (..) und des Verzeichnisses darüber (..) auf, also im Grunde das Verzeichnis zwei Ebenen oberhalb des aktuellen Verzeichnisses.
```sh
ls ../..
```
## Leeres Verzeichnis löschen
Der Befehl rmdir entfernt ein leeres Verzeichnis aus dem System. Er kann nur Verzeichnisse löschen, die keine Dateien oder Unterverzeichnisse enthalten.
```sh
rmdir
```
## Datei dauerhaft löschen (unwiderrufliches Entfernen von Dateien)
Der Befehl rm neu.txt in einer Linux-Shell löscht die Datei mit dem Namen neu.txt dauerhaft und unwiderruflich.
```sh
rm neu.txt
```
