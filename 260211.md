## Übung 4.11 (grep)

Recherchiere, experimentiere und erkläre anhand eines Beispiels die folgenden Optionen des grep Kommandos:
```sh
-i
-c
-n
```
Eine dieser Optionen wäre bei einer der vorhergehenden Aufgaben nützlich gewesen – welche?

- -i: ignoriert Groß- und Kleinschreibung
 ```sh
 grep -i lena klassenkassa.csv
 ```
- -c: zählt wie oft etwas vorkommt
```sh
grep -c Lena klassenkassa.csv
```
- -n:zeigt die Zeilennummer an
```sh
grep -n Lena klassenkassa.csv
```
## Übung 4.12 (date input format)

- Mit der Option -f - liest date ein Datum von stdin (das einzelne - steht für stdin) und stellt dieses Datum formatiert dar:
```sh
$ echo "yesterday" | date +"%d.%m.%Y (%A, KW%V)" -f -
05.02.2022 (Saturday, KW05)
```

Oder auch:
```sh
$ echo "1 days ago" | date +"%d.%m.%Y (%A, KW%V)" -f -
```
```sh
$ echo "2024-01-01 1 days ago" | date +"%d.%m.%Y (%A, KW%V)" -f -
```
Übersicht über die Syntax.

Ermittle folgende Daten:

Heute in 5 Wochen
Heute vor 5 Wochen
90 Tage nach 15.10.2023
Letzter Freitag vor einem Jahr
Kommender Freitag in 6 Monaten
1639927239 Sekunden seit 01.01.1970

- Heute in 5 Wochen:
```sh
date -d "5 weeks" +"%d.%m.%Y (%A, KW%V)"
```
- Heute vor 5 Wochen
```sh
date -d "5 weeks ago" +"%d.%m.%Y (%A, KW%V)"
```
- Letzter Freitag vor einem Jahr
```sh
date -d "1 year ago last friday" +"%d.%m.%Y (%A, KW%V)"
```
- Kommender Freitag in 6 Monaten
```sh
date -d "6 months next friday" +"%d.%m.%Y (%A, KW%V)"
```
